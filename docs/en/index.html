07 — FAQ

Before you start.

Is it really free?

Yes. NaviFox is free and open source under the GPL-3.0 license: you can use it at work too, with no subscriptions and no limits.

Windows says “Unknown publisher”. Is that normal?

Yes. The installer is not digitally signed yet, so on first launch Windows SmartScreen asks for confirmation: click More info and then Run anyway.

Do I need to install .NET or anything else?

No. The installer already includes everything it needs. All it takes is 64-bit Windows 10 or 11, and no administrator rights are required.

How does it update?

On its own: at startup NaviFox checks for a new version and downloads only the differences. You can also use Help › Check for updates.

Where are my passwords stored?

They stay on your computer, encrypted with Windows Data Protection, in %APPDATA%\Navifox. NaviFox never sends them anywhere.

Does the AI assistant read my data?

No. It receives the query and the database schema (table and column names), never the contents of the rows. With a local model (Ollama or LM Studio), nothing leaves your computer.
